# blood-tracker

Loads a [Plotly](https://plotly.com/) scatterplot of all the blood sugars I've recorded. 

## Description 

I've recorded many blood sugars over multiple devices. Since I've done well logging the data, I decided it was time to make a scatter plot to present the data. 

## Start Up

Load Blood Sugars in `./static/sugars.js`
Then open `index.html`
